# Smark Connect - Official Landing Page & Onboarding

Welcome to the standalone repository for the **Smark Connect** landing page, pricing, documentation, and interactive onboarding flow.

## 🚀 Features

- **Landing Page (`index.html`)**: Ambient dot matrix canvas, dynamic multi-layered wave ribbon animation, interactive search query bar, and parallax sections.
- **Interactive Onboarding Flow (`onboarding.html`)**: Step-by-step onboarding flow pre-populated directly from the landing page search query (`?url=...`).
- **Pricing (`pricing.html`)**: $59/month & $399/year plans with interactive feature breakdown.
- **Documentation (`docs.html`)**: Comprehensive product guide, agent reference table, and token management manual.

## 🌐 Live Demo & Deployment

This repository is configured with GitHub Actions for immediate static deployment to GitHub Pages.
